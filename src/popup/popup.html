How it works

  • Set Pretext saves text that auto-inserts into empty chat boxes on supported sites.
  • Clear removes the saved pretext and stops auto-insert.
  • Enhance Prompt rewrites the text currently in the chat box (not the saved panel pretext) and replaces that chat text once.
  • The panel pretext still auto-inserts on empty chats. Enhance does not change the saved panel pretext.
  • Enhance Settings - API key, model, style, language, tone, domain, format, and more.
  • Supported sites: ChatGPT, Perplexity, DeepSeek, GapGPT.
