# Prompt Assistant

A browser extension that inserts saved pretext into empty chat boxes and can rewrite the current prompt using OpenRouter. Supports ChatGPT, Perplexity, DeepSeek, GapGPT, and Gemini.

## Install

1. Download or clone this repository.
2. In Chrome, open `chrome://extensions/`, enable **Developer mode**, click **Load unpacked**, and select the folder containing `manifest.json`.
3. In Firefox, open `about:debugging#/runtime/this-firefox`, click **Load Temporary Add-on**, and select `manifest.json`.
4. Refresh any chat tabs already open.

To use **Enhance Prompt**, enter an OpenRouter API key in the extension's **Enhance Settings**.
